# 02 — 구현 계획 (Implementation Plan)

> 진행 상태의 **진실원천은 두 곳**: `docs/design/implementation-prompts.md` 의 P1~P12
> 체크박스(착수 단위)와 `docs/design/README.md` §1 표(웨이브 단위). 본 문서는 운영
> 절차와 로봇 유/무 트랙 분류를 정의하며, 상태를 중복 기록하지 않는다.

## 1. 작업 단위와 실행 방식

- 작업 단위 = **P1~P12** (의존 순서 정렬). 각 P 는 새 Claude Code 세션에
  `implementation-prompts.md` 의 해당 블록을 복붙해 실행한다.
- 각 P 프롬프트에 내장된 의무: 설계 문서 §참조 → 구현 → 테스트 증거 제시 → 실기 단계 전
  정지 → `README.md` 현황 표 + 프롬프트 체크박스 갱신 → Conventional Commit.
- 리뷰 게이트: 구현 완료 시 `04_REVIEW_CHECKLIST.md` 로 검수, 결과를
  `05_FABLE_REVIEW_RESULT.md` 에 기록, 요약을 `06_IMPLEMENTATION_SUMMARY.md` 에 적립.

## 3. 세션 운영 규칙

- 병렬 세션 허용 조합: 서로 다른 영역(예: P3 ∥ P11)만. 같은 파일군을 만지는 P 는 직렬.
- 컨텍스트 50% 규칙: P 하나 = 세션 하나가 기본. 큰 P(P3)는 내부 커밋 단위(O0 → W1 → O1)로
  쪼개 진행하고 중간 커밋을 남긴다.
- 모든 수치·상수는 설계 문서가 지정한 단일 정의 파일에 집결(드리프트 방지).
