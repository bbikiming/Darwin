# CM-730 / CM-740 — Sub-Controller 명세

> ROBOTIS DARwIn-OP의 sub-controller. **CM-730 = OP1, CM-740 = OP2**. 펌웨어
> ABI는 호환이며 같은 `ID 200`으로 어드레스. PCB 외형·일부 핀 위치만 차이.

## 칩

- **CM-730**: STM32F103RE Cortex-M3, 72 MHz, 512 KB Flash, 64 KB SRAM
- **CM-740**: 같은 STM32 패밀리(공식 미세 변경), 외형만 작아짐
- 펌웨어 부트로더: STM32 내장 USART 부트로더 (factory) + ROBOTIS 자체 부트로더 (USB)

## 외부 인터페이스

| 포트 | OP1 (CM-730) | OP2 (CM-740) |
|------|-------------|--------------|
| USB | Mini-B (back panel), FTDI FT232 / Apple In-Kernel | revised header location, 동일 칩 |
| Dynamixel TTL | 6× 3-pin Molex (J1..J6) | 6× 동일 |
| 외부 Dynamixel (FSR 등) | 3-pin J8 | 동일 |
| 5-pin GPIO | J7 | 동일 |
| 오디오 | 3.5 mm 잭 (mic-in / line-out) | **제거됨** |
| Mini-HDMI | 없음 | **추가됨** |
| 전원 | DC jack 12 V + 배터리 (Deans) | 동일 |
| LED | 3× chest panel + 좌우 head + 좌우 eye RGB | 동일 |
| 버튼 | mode / start (2개) | 동일 |
| 스위치 | 전원 슬라이드 | 동일 |

## 펌웨어 업로드

> ⚠️ **부록 A — 펌웨어 업로드는 사용자 명시 확인 전 절대 수행 금지.**

방법:
1. **RoboPlus / DXL Wizard (Windows)** — 공식, 우리는 사용 안 함.
2. **dynamixel-workbench (ROS, Linux)** — 명령행, 우리는 Mac이라 불사용.
3. **STM32 USART 부트로더** — Boot 핀 강제 후 외부 ST-Link 사용. 벽돌 위험 매우 높음, 사용자 직접 처리.
4. **ROBOTIS 자체 USB 부트로더** — CM-730 firmware update를 ROBOTIS 도구로 수행. 우리 forge CLI에서는 제공하지 않음 (사용자가 명시 요청 시 별도 ADR로 결정).

## 직렬 통신 (호스트 측)

- macOS: `/dev/cu.usbserial-XXXXXX` (FTDI 직결) 또는 `/dev/cu.usbmodemNNNN` (CDC, U2D2 케이스)
- Baud: 1 000 000 (default), fallback 576 000
- Frame: 8-N-1, no flow control
- Latency: macOS는 FTDI latency timer를 1 ms로 줄여야 함 (Phase 3 Mac driver setup 문서 참조)

## 부팅 순서 (관찰)

1. 배터리/DC 연결 → CM-730 전원 LED 켜짐
2. `DXL_POWER` 자동 set (firmware) → 모든 모터에 11.1 V 공급
3. PC 측 USB enumerate (FTDI 디바이스 등장)
4. 사용자 또는 forge가 `/dev/cu.usbserial-*` open
5. 첫 명령은 `PING ID 200`로 보드 응답 확인
6. `BULK_READ`로 IMU·voltage 폴링 시작
