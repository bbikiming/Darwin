# v1.1 — WalkLab Fall Prevention 고도화

**대상**: WalkLab 페이지의 보행/모션 동작에 자이로 센서 기반 균형 보정 + 낙상 예방.

**원칙**:
- ✅ **기존 기능 보존** — sim mode, 30° emergency stop, 보행 cycle 실 송출 모두 유지
- ✅ **Additive only** — 기존 동작 경로 변경 X, 새 기능만 추가
- ✅ **연결 상태 토글** — 실 robot 연결 시 실 IMU, 미연결 시 sim
- ✅ **사용자 명시적 OFF 옵션** — 자동 fall prevention 토글 (default ON)

## 5-Stage 플랜

### Stage 1 — 실 IMU wire-up (즉시 가능, 30분)

**현재**: `WalkLabSession.imuRollDeg/imuPitchDeg` 가 sim 값만.

**변경**:
- `WalkLabSession.tick()` 의 IMU 갱신 분기:
  - `store?.bus != nil` (실 robot 연결) + `!imuFilter.isStale()` → `store.imuFilter.rollDeg/pitchDeg` 사용
  - 그 외 (sim) → 기존 `updateSimIMU()`
- ConnectionStore 가 이미 5Hz polling 으로 `imuFilter` 갱신 중 — 새 polling 불필요
- 새 published: `imuSource: ImuSource { case sim, real, stale }` (UI 표시용)

**검증**:
- 실 IMU 30° 도달 시 기존 L3 게이트가 자동 발동
- 회귀: `WalkLabSessionTests.testRealImuOverridesSim` — store attach + imuFilter 갱신 → session.imuRollDeg 가 실 값
- 위험: 낮음 (read-only)

### Stage 2 — 다단계 안전 임계 (1시간)

| 임계 | 동작 | UI 색 | Walk Engine |
|---|---|---|---|
| < 15° | 정상 | 녹 (green) | 100% 속도 |
| 15-22° | Caution | 노 (yellow) | 100% (UI 경고만) |
| 22-28° | Warning | 주 (orange) | **70% 속도 자동 감속** |
| 28-30° | Danger | 빨 (red) | **자세 동결** (cycle 일시 정지) |
| ≥ 30° | Emergency | 빨 깜빡 | **토크 OFF + walkReady 복귀** (기존) |

**변경**:
- `WalkLabSession.balanceState: BalanceState { case normal, caution, warning, danger, emergency }`
- `tick()` 내부 임계 분기 — Warning/Danger 에서 `WalkEngine.setCommand(x*0.7, ...)` 또는 `enabled=false`
- `WalkLabView` 색대역 IMU 게이지 (`IMUGauge.swift` 의 4 단계 색 그대로 활용)
- 신규 토글: `autoFallPrevention: Bool` (default true) — false 면 emergency 만 발동

**검증**:
- 회귀: 각 임계에서 expected behavior 검증
- UI snapshot test (선택)
- 위험: 낮음 — 감속·정지만, 추가 송출 없음

### Stage 3 — 예측 fall detection (2시간)

**알고리즘** — IMU ring buffer (지난 500ms, 5Hz polling 이므로 ~3 sample):
- **Pitch rate** (deg/s) — 최근 sample 간 변화율
- **Gyro variance** — 최근 sample 의 gyro_x/y 분산
- **선제 emergency 조건**:
  - Pitch rate > 60 deg/s **AND** 현재 |pitch| > 20° → 0.5s 후 30° 도달 예측
  - Roll rate > 60 deg/s **AND** 현재 |roll| > 20° → 동일

**변경**:
- `FallPredictor.swift` (신규) — pure function, IMU 시계열 → predicted_fall_in_ms
- `WalkLabSession.tick()` 가 predictor 호출 후 임계 초과 시 emergencyStop
- 신규 published: `predictedFallScore: Double` (0..100), `predictedFallEtaMs: Double?`

**검증**:
- 합성 IMU sample (gyro spike) → predictor 가 emergency 발동
- 회귀: false positive rate < 5% (정상 보행에서 잘못 발동 안 함)
- 위험: 낮음 — 보수적 추정, 단지 정지 더 빨라짐

### Stage 4 — 실 balance feedback (Walking.cpp gain 포팅, ~3-4일)

**가장 위험한 단계** — 실 모터 송출에 IMU correction delta 더함.

**현재 코드**: `WalkParams.balance_*_gain` 정의됨, 활용 0.

**변경 (단계적)**:
- 4a) `BalanceCorrector.swift` (신규) — pure function:
  - 입력: `RobotPose` (현재 step 의 target pose), `(rollDeg, pitchDeg)` (현 IMU)
  - 출력: 보정된 `RobotPose` — `hip_roll`, `ankle_roll` (roll error), `knee`, `ankle_pitch` (pitch error) 에 delta
  - PID 단순화: `correction = balance_gain * error` (D-term 추가 시 oscillation 감소)
- 4b) `WalkLabSession.runWalkCycle` (실 송출 경로) 가 corrector 호출 → 보정된 pose 송출
- 4c) 사용자 토글: `enableBalanceCorrection: Bool` (default OFF — Stage 4는 실험)
- 4d) 회귀 + Mac 검증 후 default ON

**검증**:
- 단위 테스트: 합성 pose + 5° roll → 보정 후 hip_roll/ankle_roll delta 부호·크기 검증
- Codex audit — 실 motor 송출이라 외부 검수 필수
- Mac 실 robot 검증 — cradle 거치 후 점진 검증 (작은 gain → 큰 gain)
- 위험: 🔴 중간~높음 — oscillation 가능, 검증 부족 시 낙상 위험

**BLOCKER C3 의존**: 실 IK 가 있으면 더 정확. IK 없이 raw delta 도 효과 있음 (NimbRo 의 단순 patch 패턴).

### Stage 5 — UI 통합 (Stage 1-3 와 병행, 1시간)

**변경**:
- `IMUGauge.swift` — 4 임계 색대역 명시 (현재 < 15 / < 25 / < 30 / ≥ 30 → Stage 2 의 < 15 / < 22 / < 28 / ≥ 30 으로 정밀화)
- 신규 view `FallPredictionCard.swift`:
  - 예측 안정도 score (0..100) 게이지
  - "Predicted fall in: N ms" countdown (Stage 3)
  - "Balance correction: ON / OFF" 토글 (Stage 4)
- `WalkLabView` 의 detail 영역에 추가
- 회귀: UI snapshot (선택)
