### 무채색 (Achromatic) Invariant

flat 표면 색상은 모든 RGB 채널 동일 (r=g=b):
- `flatCanvas` r=g=b=1.0 (순백)
- `flatCard` r=g=b=0.985
- `flatElev2` r=g=b=0.965
- `flatElev3` r=g=b=0.940
- `flatBorder` r=g=b=0.860

상태 색상 (forge/danger/success/...) 은 `.saturation(0)` modifier 가 자동 desaturate → 진정한 grayscale.

## 8. 사용 시작

```bash
cd app/ui/DarwinForge
swift build
swift run DarwinForgeApp
```

1. WalkLab 진입 → 보행 (baseline 세션) 수집
2. "보행 데이터" 메뉴 → "Critic V2 (typed)" → baseline 분석
3. ApprovalUI sheet → 검토 → "실험 시작"
4. 다음 보행 → 자동 A/B 비교 → ActiveExperimentBanner 의 verdict
5. 만족하면 "수락 (완료)", 아니면 "Rollback"
6. 테마 변경 — 메뉴 → 테마 또는 ⌘⇧T

상세 검증 sequence: [`docs/guides/REAL_ROBOT_E2E_GUIDE.md`](../guides/REAL_ROBOT_E2E_GUIDE.md)
