# Unity ML-Agents — 게임 엔진 RL

## 한 줄 소개

Unity Engine 위 ML-Agents 패키지. C# 게임 환경에서 PyTorch 정책 학습.

## 핵심 정보

| 항목 | 내용 |
|------|------|
| 라이선스 | Unity Personal 무료 (수익 100k USD 미만) |
| 플랫폼 | Win / macOS / Linux (학습 시 GPU 권장) |
| 언어 | C# (env) + Python (학습) |
| 강점 | 게임 엔진의 표현력 (시각·소리), Apple Silicon 네이티브 |

## 우리 가능성

DARwIn-OP의 URDF를 Unity에 import (URDF Importer 패키지) + ML-Agents
환경 구성 → walk 학습. **macOS Apple Silicon에서 즉시 시도 가능**한
유일한 게임 엔진 RL 플랫폼.

## 차용 우선순위

★★ — Isaac Lab 다음. macOS 네이티브가 결정적 장점.
