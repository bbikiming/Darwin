# LLM-로봇 최신 (2024~2026)

> 분야가 폭발적으로 성장 중. 인용 시점 명시.

## Foundation 모델 / VLA

### 1. Brohan et al. (Google DeepMind, 2023~)
**RT-2: Vision-Language-Action Models Transfer Web Knowledge to Robotic Control**
→ VLA의 본격 출발.

### 2. Black et al. (Physical Intelligence, 2024)
**π0: A Vision-Language-Action Flow Model for General Robot Control**
→ Physical Intelligence (Sergey Levine 외) 발표.

### 3. NVIDIA (2024)
**GR00T N1 / GR00T**
→ GTC 2024 발표 + 2025 확장.

### 4. Figure (2024)
**Helix: Vision-Language-Action Model for Humanoid Robots**
→ 듀얼 시스템 (System 1 빠른 반응 + System 2 추론). DarwinForge 자연어 통합 패러다임의 직접 본보기.

### 5. Stanford / Berkeley (2024)
**OpenVLA: Open-Source Vision-Language-Action Model**
→ Apache 2.0. 우리가 시도해 볼 수 있는 오픈 모델.

### 6. Berkeley (2024)
**Octo: An Open-Source Generalist Robot Policy**
→ 또 다른 오픈 VLA.

## LLM-as-Planner

### 7. Ahn et al. (Google, 2022)
**Do As I Can, Not As I Say (SayCan)**
→ affordance × LLM 점수 결합.

### 8. Liang et al. (Google, 2023)
**Code as Policies: Language Model Programs for Embodied Control**
→ LLM이 Python 정책 코드 생성. DarwinForge가 Sprint 8에 차용 후보.

### 9. Huang et al. (Stanford, 2023)
**VoxPoser: Composable 3D Value Maps for Robotic Manipulation with LLMs**
→ 3D voxel cost map 생성.

## 안전 / 검증

### 10. Anthropic (2022)
**Constitutional AI: Harmlessness from AI Feedback**
→ 우리 L1 (Refusal) 근거.

### 11. Liu et al. (2024)
**VerifyLLM: Pre/Post-condition verification for LLM-generated robot code**
→ 우리 5계층의 L3 + L4 보강 후보.

## RL 기반 휴머노이드 워크 (최신)

### 12. Radosavovic et al. (Berkeley, 2024)
**Real-World Humanoid Locomotion with Reinforcement Learning**
→ Digit 또는 H1 RL 워크.

### 13. Cheng et al. (CMU, 2024)
**Expressive Whole-Body Control for Humanoid Robots**
→ Unitree G1 기반.

## Eureka / 자동 reward shaping

### 14. Ma et al. (NVIDIA, 2023)
**Eureka: Human-Level Reward Design via Coding Large Language Models**
→ LLM이 reward 함수 생성. DarwinForge가 "더 자연스러운 워크" 학습 시 적용.

### 15. Ma et al. (NVIDIA, 2024)
**DrEureka: Domain Randomization 자동화**

## MCP / Agent 표준

### 16. Anthropic (2024)
**Model Context Protocol (MCP)**
→ 우리 forge-mcp expose 후보.
