# Genesis — 차세대 통합 시뮬레이터 (CMU 2024)

## 한 줄 소개

Carnegie Mellon University 주도 (2024년 12월 공개). 단일 엔진에서 강체·
연체·유체·천 시뮬을 모두 GPU 가속으로 처리. 곡선이 가장 가파르게 상승하는
플랫폼.

## 핵심 정보

| 항목 | 내용 |
|------|------|
| 라이선스 | Apache 2.0 |
| 플랫폼 | Linux / macOS / Windows |
| 언어 | Python (Taichi 기반) |
| 강점 | 단일 엔진에서 강체+연체+유체, GPU 가속 |
| 약점 | 1.0 미달, 안정성 검증 진행중 (2024-2025 기준) |
| 출시 | 2024-12 |

## 왜 흥미로운가

- **단일 백엔드** — 모션, 매니퓰레이션 (천·유체 포함) 통합.
- **빠른 학습 속도** — IsaacGym급 처리량을 macOS에서도 (확인 필요).
- 향후 휴머노이드 표준이 될 가능성.
