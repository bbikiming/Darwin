# OPC UA — Open Platform Communications Unified Architecture

## 한 줄 소개

산업 자동화 표준 통신. 공장 PLC / SCADA / MES 통합. DarwinForge가 산업
환경에 배치될 때만 의미.

## 핵심 정보

| 항목 | 내용 |
|------|------|
| 표준 | IEC 62541 |
| 라이선스 | OPC Foundation 멤버십 (오픈 사양) |
| 구현 | open62541 (Apache 2.0), Milo (Eclipse), python-opcua |
| 사용처 | Siemens / Rockwell / ABB PLC, 공장 OEE |

## DarwinForge 적용

★ — 매우 낮음. 우리는 산업 라인이 아닌 데스크탑 / 교육 / 시연용.

가상 시나리오: DARwIn-OP가 공장 시연 부스에 배치되어 OPC UA로 SCADA에
"오늘 시연 횟수" 보고. 실용적 가치 X.
