# 14. 의료 / 외골격 로봇

> DarwinForge 직접 무관. 안전 등급·환자 상호작용 UX 면에서만 영감.
> 본 카테고리는 placeholder + 핵심 시사점만.

## 핵심 사례

### 1. Intuitive Surgical da Vinci ★

수술 로봇 글로벌 표준. UX 측면:
- **Tele-presence** — 외과의가 콘솔에서 손 + 발로 정밀 조작
- **Force feedback** — 일부 모델, 최신 X / Xi에 추가
- **Safety lock** — 거리 임계 초과 시 즉시 정지

DarwinForge에 영감: 거리 / 속도 임계 시 자동 정지 패턴 (이미 ISO 13855 채택).

### 2. ReWalk / Ekso Bionics — 외골격

척수 손상 환자 보행 보조. UX 측면:
- **명백한 진행률 시각화** (남은 힘, 배터리)
- **사용자 자기효능감** — 사람이 주체, 로봇은 보조

DarwinForge에 영감: 시뮬 vs 실기 모드 토글 시 사용자에게 통제 권한 명시.

### 3. Cyberdyne HAL

EEG 기반 의도 추정 외골격. 우리 스코프 외.

## 의료 표준

- **ISO 13485** — 의료기기 품질
- **IEC 60601-1** — 의료기기 기본 안전
- **FDA 510(k)** — 미국 의료기기 승인
- **MDR 2017/745** — EU 의료기기

DarwinForge는 의료기기 X. 그러나 사용 사례가 교육 / 시연이 아닌 환자
재활로 확장된다면 위 표준 검토 필요.

## 차용 우선순위

★ — 6순위. DarwinForge 직접 적용 X. UX 패턴 (사용자 자기효능감, 진행률,
자동 정지)만 참고.
