## §0 목적·범위·불변식

**결론 먼저**: DARwIn FPV 의 UI 는 "FPV 드론 고글 + 메크 시뮬레이터 콕핏"의 문법을 차용한
**풀블리드 영상 중심 + 좌우 MFD 레일** 구성이다. 게임의 재미 문법(부팅 시퀀스·디제틱 콕핏·
텔레메트리 클러스터)은 적극 차용하되, **안전 메시지·E-STOP 경로에는 게임 연출을 전면 금지**한다.
모든 수치(매핑·와이어·색)는 이 리포에서 실기 검증된 세 조상(Mac 콕핏 / RG G01 직결 파일럿 /
Switch 웹 콕핏)에서 직계승하며 재발명하지 않는다.

## §R 레퍼런스 분석 — 무엇을, 어디서, 왜 차용하는가

방법론: 레퍼런스마다 "차용 항목"을 **구체 문법 단위**로 적고, 적용처(화면·컴포넌트)를 명시하며,
**차용하지 않는 것**을 같은 행에 박아 범람을 막는다.

**전면 금지 목록** (모든 화면 공통):

- **화면 셰이크** — 어떤 상태에서도. 실기 조종 중 시야 흔들림은 안전 문제.
- **반복 경고음 루프** — 현장(시연장·실험실)의 소음 공해. 모든 경고음은 1회 발성(§A).
- **피해/사망 연출** — 낙상은 "복구 가능한 상태"이지 게임오버가 아니다(§X·§W).
- **장식성 스캔라인·글리치 과다** — CRT 노이즈·글리치 이펙트는 카메라 신호 이상과 시각적으로
  구분 불가능해진다. 영상 영역에는 장식 노이즈 절대 금지.

## §T 타이포그래피 · 터치 스케일 — 근거 계산

### T.1 물리 기반 계산 (7" 1080p, 시청거리 ~40cm)

```
화면 대각:  √(1920² + 1080²) = 2202.9 px
밀도:       2202.9 / 7"      = 314.7 ppi  ≈ 314ppi
환산:       1 mm  = 314.7 / 25.4 = 12.39 ≈ 12.4 px
시야각:     40cm 에서 1° = 2 × 400mm × tan(0.5°) = 6.98 ≈ 7.0 mm ≈ 86.5 ≈ 86 px
```

함의: ROG Ally 는 **손에 들고 보는 고밀도 화면**이다. 데스크톱 픽셀 감각(16px 본문)을 그대로
쓰면 물리 1.3mm 글자가 된다. 최소 가독 본문을 약 22px(≈1.8mm, 시야각 ~0.26°)로 끌어올리고,
주행 중 읽는 값은 28px 이상으로 둔다.

### T.3 터치 타깃

| 등급 | px | 물리 | 용도 |
|---|---|---|---|
| 보조 | 100 × 100 | 8.1 mm | 메뉴 보조 액션, 디클러터 칩 |

Switch 웹 콕핏은 1280×720 기준이므로 1080p 는 정확히 1.5×. 기계적 1.5× 가 아니라
**1.5× 환산 후 8px 그리드와 용도에 맞춰 스냅**한 채택값을 쓴다.

### S.2 화면별 정의

**① 스플래시** — 로고 + 백그라운드 자가점검(≤3s)
- 점검 3항목을 t-200 캡션으로 순차 표기: **네트워크 어댑터**(유선 USB-C LAN 감지 포함) ·
  **패드 인식**(내장 XInput) · **방화벽**(UDP 17371/17372/17374 인바운드 — Windows 방화벽 규칙 존재 확인).

- 완료 시 "Ⓐ 시작" 글리프. 자가점검은 진행을 막지 않는다(경고만 들고 다음 화면으로).

**② 커넥트 — 서버 브라우저** (멀티플레이 서버 브라우저 문법)
- 로봇 카드 1행(높이 124px): `이름 · IP · RTT(ms) · TEL 하트비트 점 · 배터리(dV→V) ·
  WIRED/WIRELESS 배지`.
- **유선(192.168.123.1) 감지 시 최상단 우선 정렬** + WIRED 배지 시안 강조(유선이 ~166× 빠르다는
  운영 사실의 UI 반영).
- 키: **Ⓐ 연결 · Ⓧ 진단(핑/포트/SSH 검사 패널) · Ⓨ 직접 IP 입력**(온스크린 키패드, 터치 병용).
- 빈 목록 상태: "발견된 로봇 없음 — 유선 케이블 연결 또는 Ⓨ 직접 IP".

**③ 출격 시퀀스** (MechWarrior 부팅 문법 — 단, 전 단계에서 E-STOP 즉시 유효)
1. **자동 체크리스트 4항목 순차 점등** (항목당 점등 애니메이션 200ms, 실패 시 그 자리에 호박 표시·진행 중단):
   `LINK`(핸드셰이크 채택 + ACK) → `TELEMETRY`(TEL2 수신 개시) → `CAMERA`(MJPEG 첫 프레임)
   → `POSTURE`(TEL2 fallen 아님)
2. **"RT + Ⓐ 0.8s 홀드"** — 원형 게이지가 차오르는 의도 확인(우발 ARM 방지. 슬라이더 대신
   패드 친화 홀드 게이트 — Mac ARM 슬라이더 80% 임계의 패드 등가물).
3. **토크 램프 진행** — 300→600→900→1023 4단계를 단계 점등 + % 표시(150ms 간격, 총 ~0.6s.
   실제 로봇 측 `SG_SOFT_RAMP_VALUES` 진행을 표시 — 연출이 아니라 실황 보고).
4. **HUD 전환** — 상태블록 standby(호박) → live(그린), OSD 요소가 **200ms stagger** 로 점등.
- E-STOP(B·터치)은 1~4 전 단계에서 즉시 유효(INV-1). `reduce-motion` 설정 시 점등 연출 생략,
  체크 결과만 즉시 표시.

**④ 콕핏** — §H 전체.

**⑤ 일시정지 메뉴** (Menu 버튼)
- **진입 즉시 Rust 가 이동 0 합성**(콕핏 입력 차단 — 메뉴 보면서 로봇이 걷는 사고 방지).

## §H 콕핏 HUD 레이아웃 — 1920×1080 픽셀 좌표

### H.1 핵심 결정 — 필러박스를 지우지 말고 MFD 레일로 전용한다

카메라는 MJPEG 320×240(4:3). 1080p 에서 **fill-height 스케일 → 1440×1080**, 좌우에
**240px 필러박스**가 정확히 남는다(1080 × 320/240 = 1440, (1920−1440)/2 = 240).
이 240px 를 검은 띠로 버리는 대신 **DCS 식 독립 MFD 레일**로 전용한다 — 영상은 단 1px 도
가리지 않으면서 콕핏 정보 밀도를 확보하는, 이 레이아웃의 존재 이유.

모든 전이는 **표시 레이어에만** 존재한다 — 어떤 모션도 명령·E-STOP 타이밍에 관여하지 않는다(INV-1·2).

## §A 사운드 · 햅틱 — 전부 신규 (선례 3종 모두 무음)

Mac 콕핏·G01 직결·Switch 콕핏 어느 조상도 사운드가 없다. 따라서 본 절은 차용이 아닌 신규 설계이며,
원칙은 Elite Dangerous 의 절제: **짧게, 1회만, 의미당 한 소리**.

### A.1 사운드 큐

| 큐 | 발생 | 설계 | 반복 |
|---|---|---|---|
| UI 틱 | 포커스 이동 | 5ms 클릭, −24dB(거의 촉각적) | 이동마다 |
| 확인음 | Ⓐ 확정 | 짧은 상승 2음 | 1회 |
| ARM 램프업 톤 | 출격 3단계 | 4단 상승 톤 — **토크 램프 300→600→900→1023 의 150ms 간격과 동기**(소리가 곧 실황) | 1회 |
| ARMED 차임 | live 전환 | 단정한 1음 | 1회 |
| **E-STOP 클락슨** | E-STOP 발화 | **2음 하강 클락슨, 단 1회** — 발화는 INV-1 즉시, 소리는 사후 보고 | **1회. 루프 절대 금지** |
| 링크 경고 | TEL 침묵 >1.5s 진입 | 상승 2음 1회 | 상태 지속돼도 재생 안 함(재진입 시만) |
| 낙상 알림 | fallen 감지 | 중립적 2음(경고음과 구분되는 부드러운 음색 — 복구 가능 상태) | 1회 |
| 보행 위상 메트로놈 | TEL2 `phase` 동기 틱 | 보행 케이던스의 청각 피드백(period 560–700ms 와 동기) | **기본 OFF** (설정 옵트인) |

설정: 마스터 볼륨 · 뮤트 · **현장 데모 프리셋**(= UI 틱·확인음·메트로놈 끄고 경고음만 —
시연장에서 스피커 소음 최소화).

### A.2 햅틱 (XInput 럼블) — 사운드와 항상 쌍

현장은 시끄럽다. 모든 안전 관련 큐는 **소리+진동 동시**로 나가 소음 환경을 보완한다.

| 큐 | 패턴 |
|---|---|
| ARM 완료 | 더블 펄스(약, 60ms ×2) |
| **E-STOP 발화** | **강한 단일 300ms** |
| 낙상 감지 | 중간 펄스 ×2 |
| 링크 끊김(SIGNAL LOST 진입) | 약한 페이드아웃 400ms |

햅틱만 따로 끌 수 있으나, E-STOP 햅틱은 마스터 뮤트와 무관하게 항상 발생(설정 불가 — 안전 피드백).
